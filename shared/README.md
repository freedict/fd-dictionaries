This directory contains the schemas for validating FreeDict TEI P5.
The ODD schema is in freedict-P5.xml. From it, all other schema formats are
derived.
The Makefile assists in regenerating the schemas from the ODD file in
freedict-P5.xml.

# Dependencies

You should hagve at least this software installed:

-   ant
-   libxml-commons-resolver1.1-java

Xmllint or Jing are enough if you want to validate a dictionary against the
FreeDict schemas.
